# Prompt — Criar Deck a partir de uma Referência Visual

Receba uma URL, screenshot, brandbook ou apresentação de referência e extraia:
- personalidade;
- paleta;
- contraste;
- escala tipográfica;
- grid;
- formas;
- tratamento de imagem;
- densidade;
- ritmo;
- estilo de gráficos;
- linguagem de CTA.

Converta isso em um Design DNA original para a apresentação. Não replique literalmente layouts protegidos nem trate a referência como um template a ser copiado.
