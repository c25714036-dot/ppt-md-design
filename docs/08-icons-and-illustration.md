# 08 — Ícones e Ilustração

## Ícones

Use ícones para reconhecimento e navegação, não para preencher espaço.

Mantenha:
- mesmo conjunto;
- mesma espessura de traço;
- mesmo tratamento de cor;
- escala óptica consistente.

## Ilustrações

Defina uma linguagem:
- isométrica;
- flat;
- line art;
- 3D;
- editorial;
- diagramática.

Não misture estilos sem motivo.

## Ícone + texto

Se o ícone não acrescenta significado, remova. Muitos decks ficam mais sofisticados com tipografia e composição do que com dezenas de pictogramas.
