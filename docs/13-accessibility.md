# 13 — Acessibilidade

## Legibilidade

- tamanho de fonte adequado;
- contraste suficiente;
- textos curtos;
- espaçamento confortável;
- não depender apenas de cor para significado.

## Daltonismo

Em gráficos, combine cor com:
- rótulos;
- padrões;
- espessuras;
- formas;
- posição.

## Leitura

A ordem de leitura deve ser previsível. Evite layouts visualmente interessantes que confundem sequência.

## Texto alternativo

Quando a plataforma suportar e o contexto exigir, adicione alt text a imagens e gráficos relevantes.
