# 16 — Adaptação de Marca

## Objetivo

Transformar identidade de marca em linguagem de apresentação sem simplesmente aplicar logo + cores.

## Extraia

- tom;
- proporções;
- tipografia;
- linguagem fotográfica;
- formas;
- padrões;
- nível de contraste;
- densidade;
- comportamento de CTA;
- iconografia.

## Se houver site como referência

Observe:
- hero;
- navegação;
- módulos;
- cards;
- escalas de título;
- espaçamento;
- fotos;
- motion;
- tratamento de dados.

Traduza princípios para slides; não copie a página como se fosse um screenshot.

## Se houver brandbook

Priorize regras oficiais. Quando o brandbook não cobre apresentações, crie extensões coerentes e documente-as no Design Contract.
