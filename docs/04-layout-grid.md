# 04 — Layout e Grid

## Grid-base

Para 16:9, um sistema de 12 colunas é flexível. Use margens consistentes e gutters regulares.

## Zonas

Divida o slide em zonas funcionais:
- título;
- conteúdo principal;
- evidência;
- navegação/rodapé.

Nem todo slide precisa ocupar todas as zonas.

## Regras de alinhamento

- alinhe objetos por eixos compartilhados;
- evite “quase alinhado”;
- mantenha distâncias repetíveis;
- alinhe textos pela caixa óptica, não apenas pela matemática;
- não centralize blocos longos sem necessidade.

## Assimetria

Assimetria é útil para:
- criar foco;
- abrir espaço para imagem;
- orientar leitura;
- aumentar sofisticação editorial.

## Espaço em branco

Whitespace deve separar, destacar ou criar ritmo. Espaço vazio sem função não é minimalismo.

## Safe area

Mantenha conteúdo crítico distante das bordas, especialmente em ambientes com projetores, TVs e exportações diferentes.

## Layout families

Crie famílias, não slides isolados:
- abertura;
- conteúdo 1 coluna;
- conteúdo 2 colunas;
- dados;
- processo;
- comparação;
- prova social;
- fechamento.
