# 05 — Tipografia

## Objetivo

A tipografia deve permitir leitura rápida a distância e sustentar a personalidade da marca.

## Hierarquia

Use diferenças claras entre:
- título;
- subtítulo;
- corpo;
- labels;
- números;
- notas.

## Escala

Prefira uma escala limitada e repetível. Evite tamanhos únicos para cada slide.

## Peso

Peso tipográfico comunica hierarquia. Não dependa apenas de tamanho.

## Comprimento de linha

Textos longos ficam mais legíveis quando a largura é controlada. Evite ocupar todo o slide com uma linha de corpo.

## Caixa alta

Use com parcimônia em labels curtos. Evite parágrafos inteiros em caixa alta.

## Pares de fontes

Um sistema robusto pode usar:
- uma família única com vários pesos; ou
- uma display para títulos + uma sans/serif de leitura.

## PowerPoint

Se o arquivo será compartilhado como editável, considere disponibilidade das fontes. Quando necessário, use alternativas seguras ou incorporação permitida.
