# 17 — Diagramas e Frameworks

## Quando usar

Diagramas são úteis quando a relação entre elementos é mais importante do que cada elemento isolado.

## Tipos

### Fluxo
Para sequência, aprovação ou processo operacional.

### Sistema
Para componentes interdependentes.

### Funil
Para redução progressiva ou conversão. Não use apenas porque o tema é marketing.

### Loop
Para ciclos realmente recorrentes.

### Camadas
Para arquitetura, maturidade ou dependência.

### Matriz 2x2
Para classificação em duas dimensões. Nomeie quadrantes apenas se isso acrescentar decisão.

### Árvore
Para decomposição hierárquica.

## Regras

- reduza cruzamentos de conectores;
- mantenha direção consistente;
- use poucas formas;
- rotule relações importantes;
- evite decorar diagramas com ícones desnecessários;
- transforme diagramas complexos em sequência de slides quando a leitura simultânea ficar difícil.
