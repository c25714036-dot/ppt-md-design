# 19 — Capa, Seções e Fechamento

## Capa

A capa deve definir o tom do deck. Elementos essenciais:
- título específico;
- subtítulo quando necessário;
- marca;
- data/contexto quando relevante.

Não transforme a capa em um resumo executivo.

## Capa com imagem

Escolha uma imagem que estabeleça contexto ou emoção, não apenas algo visualmente atraente.

## Section divider

Use para marcar mudança real de capítulo. Pode funcionar como respiro visual.

## Closing

Feche com:
- decisão solicitada;
- próximos passos;
- CTA;
- contato;
- visão futura.

Evite encerrar apenas com “Obrigado” se existe uma ação mais útil para a audiência.
