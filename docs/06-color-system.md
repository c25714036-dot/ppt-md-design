# 06 — Sistema de Cor

## Estrutura

Defina:
- primary;
- secondary/accent;
- neutral dark;
- neutral light;
- success;
- warning;
- danger;
- information.

## Proporção

Uma cor de marca forte funciona melhor quando há espaço neutro para ela ganhar importância.

## Contraste

Texto e fundo precisam manter legibilidade em tela, projetor e PDF.

## Dados

Separe paleta de marca e paleta analítica quando necessário. Cores em gráficos devem carregar significado consistente.

## Destaque

Use uma cor de acento para responder: “onde a audiência deve olhar primeiro?”. Se tudo está destacado, nada está destacado.

## Fundos escuros

Em decks escuros, cuide de:
- blooming em telas;
- cinzas muito próximos do preto;
- linhas finas demais;
- saturação excessiva de cores brilhantes.
