# 09 — Visualização de Dados

## Comece pela pergunta

Antes de escolher o gráfico, responda:
- o que deve ser comparado?
- qual mudança importa?
- existe tendência?
- existe composição?
- existe distribuição?
- existe correlação?

## Seleção rápida

- comparação → barras;
- tendência → linhas;
- composição simples → barras empilhadas;
- distribuição → histograma/boxplot;
- relação → scatter;
- processo temporal → timeline;
- KPI principal → hero metric.

## Storytelling de dados

1. mostre contexto;
2. destaque o dado relevante;
3. escreva a conclusão;
4. indique implicação quando necessário.

## Simplificação

Remova:
- bordas desnecessárias;
- grades pesadas;
- legendas redundantes;
- casas decimais sem valor;
- efeitos 3D;
- cores sem significado.

## Cor semântica

Mantenha a mesma associação ao longo do deck. Ex.: produto A não deve mudar de azul para verde sem motivo.

## Fonte e período

Sempre registre fonte, período e unidade quando dados externos ou corporativos exigirem rastreabilidade.
