# 02 — Storytelling e Arquitetura

## Títulos que contam a história

Prefira títulos conclusivos:
- fraco: “Mercado”
- melhor: “O mercado cresceu 34% em dois anos”

- fraco: “Problema”
- melhor: “A operação perde margem em três pontos críticos”

Ao ler apenas os títulos, a narrativa deve continuar compreensível.

## Estruturas úteis

### SCQA
- Situação
- Complicação
- Pergunta
- Resposta

### Problema → Impacto → Solução → Prova → Ação
Boa para vendas e propostas.

### Insight → Evidência → Implicação → Recomendação
Boa para estratégia.

### Visão → Oportunidade → Solução → Tração → Modelo → Pedido
Boa para pitch.

### Resultado → Causa → Aprendizado → Próxima ação
Boa para relatórios.

## Pyramid Principle

Comece pela conclusão quando a audiência é executiva. Depois sustente com grupos de argumentos independentes e coletivamente suficientes.

## MECE

Ao agrupar argumentos, tente minimizar sobreposição e lacunas. Use MECE como ferramenta de clareza, não como dogma.

## Ritmo

Alterne:
- síntese;
- aprofundamento;
- prova;
- pausa visual;
- decisão.

Um deck inteiro no mesmo nível de densidade cansa.

## Section dividers

Use divisores quando houver mudança real de capítulo. Não crie separadores apenas para aumentar o número de slides.
